# Veltrix Cloud Website

Static, responsive hosting landing page inspired by the supplied Veltrix Cloud mockup.

## Before publishing
1. Open `script.js`.
2. Replace `https://discord.gg/YOUR_INVITE` with your real Discord invite.
3. Replace demo pricing in `index.html` with your real plans.
4. Add your real logo/assets if desired.

## Cloudflare Pages
- Connect this GitHub repository.
- Production branch: `main`
- Build command: `exit 0`
- Build output directory: `/`
